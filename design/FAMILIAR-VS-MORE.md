# Familiar vs More — per page

Familiar = conventions bettors already own (keep them exactly, Jakob). More = where we exceed,
each tied to a cited pain. Never "more" on the familiar skeleton itself.

## Sports home
- Familiar: sport nav, live strip, competition tiles, search in top bar, hero first.
- More: featured-fixture slideshow with real countdowns not promo banners (M4; scope-banned promos);
  follows surface "your matches" front (U1-20 continuity); progressive density — fewer, better cards (U1-17).

## Live
- Familiar: sport filters with counts, league groups, live badge + clock, odds row per match.
- More: suspension rows stay visible inline with reason (U1-4); honest "delay applies" microcopy
  (U1-15); nothing-live → Starting soon designed empty, not a dead end (scorecard ask).

## Football
- Familiar: five league groups, 1X2 row per match, scheduled+live mixed, star = follow.
- More: market selector re-binds row cells (wireframe depth); follow from anywhere incl.
  competition headers (M4); countdown chips instead of bare dates (U3 rule 10: never 0–0).

## Match page
- Familiar: scoreboard top, market-group tabs, accordions, search markets, +N counts.
- More: pinned minimal header so the board never loses context (U3/FotMob); implied% on every
  price (U4); suspension keeps last price dimmed + reason (U1-4); goal→lock→reprice causality
  sequence (S4); open bet strip visible on page (A22).

## Bet slip + My bets
- Familiar: selection cards, stake input+chips, returns, place CTA, open/settled tabs.
- More — this is where we win the 20: accept-better-only consent per leg (U1-1/2); receipt =
  ref+accepted odds (U1-12); CO live quote + reconfirm + partial + paused-not-dead (U1-5..8);
  fat-finger-proof stake (U1-9); break control reachable (U4-53); terminal states designed (U2-30).

## Phone ticket
- Familiar: bottom pill, count badge, opens sheet.
- More: pill shows the PICK not just count (U2-29); sheet follows thumb with real physics (P4);
  ticket persists across nav/reload (U1-11).
