# ELEMENT-LAW — the recurring vocabulary, frozen

If it appears twice in the product, it appears here once. No screen may redefine these.

## 1. Odds cell — THE atom
- h-44 min (touch), w≥64, r-2, surface-2 bg, border-soft 1px
- Price: Oxanium 13 bold, tabular lining, right-aligned
- Selected: accent-neon fill, dark text, ✓ before price (Housebets verbatim)
- Disabled/suspended: opacity + lock glyph — NEVER hidden (truth law)
- Moved: edge tint (success▲/error▼, 2px left) + whole-value roll; direction glyph inside cell
- Hit slop: full cell = one target, no nested zones

## 2. Team/competition identity
- Crest: SVG silhouette (custom set), 24px rows / 32px headers — NEVER emoji flags, NEVER initials-in-discs
- Names: bold 13 teams, regular 12 competition text-2†
- Fixture line grammar: `Home v Away · Competition · status`

## 3. Status chips (the only 5)
| chip | colour law | use |
|---|---|---|
| LIVE ● | live badge, blinking dot (pause control, WCAG) | live matches, live market, live ticket |
| Suspended 🔒 | warn band, amber | locked markets/legs, always + reason |
| Upcoming 🕐 | text-2† neutral | future fixtures, real countdown |
| Settled ✓/✕/∅ | success/error/warn per outcome | receipts only |
| DEMO | muted tag | wallet/prototype honesty — one place only |

## 4. Money grammar
- Currency: ₮ asset prefix (never text T), 2dp display, tabular
- Returns bold > stake; net = signed, honest
- Negative money uses text-2† (dignity, not grey-obliteration)

## 5. The hairline list (replaces cards)
- Rows separated by border-soft 1px; rows sit on surface-1 page bg
- Card boxes allowed ONLY for: receipt, receipt-equivalent moments, hero art frames
- Row anatomy: [identity] [status] [numbers] [action] — same order everywhere

## 6. Buttons (exactly 3 fills)
- Primary: cta-fill pale-cyan, cta-text dark — money/commit actions ONLY (P4 law)
- Secondary: surface-3 fill, text-1 — navigation actions
- Ghost: text-2† + underline — tertiary (clear, remove, prefs)
- DANGER: never a red filled button; destructive = ghost + confirm inline

## 7. Sheet/panel grammar
- Bottom sheet (phone): drag handle, velocity dismiss, scrim, focus trap
- Right rail (desktop): fixed, no overlay, never modal
- Dialog (deposit/search): centered, scrim, Esc, focus restore

## 8. Counts everywhere
- Every list header: `Label · N` — tabs, sections, groups (A37a)
- Counts derive from world store — a stale count is a correctness bug, not cosmetic
