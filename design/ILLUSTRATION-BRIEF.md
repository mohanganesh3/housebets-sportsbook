# ILLUSTRATION-BRIEF — the visual signature (what makes it OURS, not a template)

Goal: the first screenshot must be unmissably authored. One illustration system, applied sparingly.

## The concept — "Night Floodlights"
Housebets = a stadium at night, lit cyan. Every illustration uses the SAME grammar:
- Deep navy field (surface-0/-1 palette) with hairline pitch geometry
- ONE cyan light source — floodlight glow, never ambient neon everywhere
- Figures/forms as clean silhouettes in surface-3 tones
- Optional gold single-point accent (a seat, a flag) — restraint echoes the follow-star
- Grain/noise ≤4% so it reads hand-finished, not vector-flat

## Where illustration lives (and does NOT)
ALLOWED: masthead frames · empty-state cameos (Hubie) · competition tiles (optional crest-art variant) · the receipt's corner watermark · login-free "about demo" footer
BANNED: inside boards/lists · behind odds cells · on the slip · anywhere a price sits — prices never compete with art [P1]

## The asset set (v1 build list)
1. `masthead-derby` — two-team standoff composition, floodlit (featured match slot)
2. `masthead-final` — trophy-adjacent composition for cup fixtures
3. `masthead-generic` — stadium wide-shot fallback
4. `hubie-empty` — Hubie mascot cameo, flat 2-tone, friendly not childish
5. `hubie-error` — Hubie with a flag down / VAR pose (error states get charm not coldness)
6. `crest-art` ×N — per-competition tile backgrounds (geometric league marks — optional phase 2)
7. `pitch-geometry` — hairline pitch-line background texture for hero frames only

## Technical law
- Format: hand-built SVG (authored, animatable) or generated PNG @2x WebP — SVG preferred
- Palette-locked to tokens; gradients only as light falloff (no AI-gradient look)
- Masthead SVG can take ONE ambient animation: subtle light sweep ≤8s loop, pausable, RM=static
- Kinetic type sits ON TOP as real text (accessibility + crispness), never baked in

## Why this beats rivals
AI-template entries ship either zero illustration or generic Unsplash-style gradients. A consistent, token-locked stadium-at-night system says "a design team built this." It also echoes Housebets' own cyan-on-navy world instead of fighting it.
